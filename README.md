# Aditya Kumar — Minecraft Themed Portfolio 🎮

A high-performance personal portfolio website inspired by the modern **Minecraft Overworld daytime aesthetic** (featured on [minecraft.net/about-minecraft](https://www.minecraft.net/en-us/about-minecraft)).

Built with **React**, **Vite**, **Tailwind CSS**, and **Three.js**.

---

## 🌟 Key Features

1. **3D Interactive Minecraft Character:**
   - Real-time 3D voxel character rendered using Three.js standing on an isometric Grass Block.
   - Character head tracks your cursor smoothly.
   - Click to trigger celebratory jump animation; drag to rotate 360°.
2. **Daytime Overworld Atmosphere:**
   - Sunny Overworld sky with drifting pixel clouds and animated sun.
   - Minecraft 2.5D / isometric block cards with beveled borders and pixel drop shadows.
   - Iconic Minecraft green, diamond, and stone 3D push-down buttons.
3. **Sound Effects with Toggle (SFX: ON / OFF):**
   - Authentic Web Audio API sound synthesizer with zero latency and zero external dependencies.
   - UI button clicks, chest-opening squeaks, level-up chimes, and experience orb dings.
4. **Creative Inventory (Player Skills):**
   - Inset item slots with durability bars and stack counters (64x).
   - Minecraft lore hover tooltips with custom purple border framing and rarity color grades (Legendary, Epic, Rare).
5. **Advancements & Loot (Projects):**
   - **MessTrack (Hostel Mess Management System):** Full-stack React + Spring Boot + PostgreSQL system with JWT & RBAC. Direct links to GitHub and Live Vercel deployment.
   - **Job Tracker API:** 3-tier enterprise backend with JPA/Hibernate, clean DTOs, and global exception handling.
6. **Combat Mastery (500+ Solved):**
   - Clickable advancement banner with confetti level-up celebration.
   - Direct badges and links to LeetCode and Codeforces profiles.
7. **Quest Log (Education):**
   - Bakhtiyarpur College of Engineering, B.Tech CSE (IoT) [2024–2028], CGPA: 7.4.
8. **Multiplayer Chat (Contact):**
   - In-game chat box `/msg Aditya` with one-click direct email transmission and copyable oak signs for Email, Phone, GitHub, and LinkedIn.
9. **Bottom 9-Slot Hotbar:**
   - Pinned Minecraft hotbar supporting keyboard keys `1` through `9` for fast slot navigation.
10. **Enchanted Book Resume Modal:**
    - Printable and downloadable resume layout.

## 🚀 Running Locally

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
