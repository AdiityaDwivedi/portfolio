# Portfolio

Personal portfolio built with React, Vite, and Tailwind CSS with a Minecraft-inspired theme.

## Tech Stack

- **Frontend:** React, Tailwind CSS, Vite
- **Icons:** Lucide React & Custom SVGs
- **Audio:** Web Audio API

## Getting Started

```bash
# Clone the repository
git clone https://github.com/AdiityaDwivedi/portfolio.git

# Install dependencies
npm install

# Start development server
npm run dev
```

## Build

```bash
npm run build
```
